# Velella

Velella — a small sail on a sturdy float. A Rust core keeps it afloat; a native SwiftUI sail catches the wind.

A native macOS (26+, arm64) Discord client: UI-agnostic Rust core, SwiftUI front end, joined by UniFFI.

```
make run    # build Rust + bindings + Swift, then launch
make test   # cargo test
```
